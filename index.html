Every character is a challenge member. A meal upload sends them to the fridge, the chopping board and the stove, then to a table to eat and the sink to wash up; meal prep gets batch cooked, boxed and put in the fridge; a workout sends them to the right machine for proper sets with rests. Running on demo uploads until your app is connected.

Connect your app

  1. App sends an eventWhen a member posts a meal, meal prep or workout, your backend pushes a small JSON message to a realtime channel (Supabase Realtime, Firebase, Pusher or your own WebSocket).
  2. Host this sceneSave the page as an .html file on any web host and paste your channel address into FEED.websocketUrl (or a JSON endpoint into FEED.pollUrl) at the top of the script.
  3. Stream it in 4KIn OBS add a Browser Source at 3840×2160 (or 1920×1080) pointing at that page, then go live to YouTube and Kick. For 24/7 streaming, run OBS on a cloud machine with a GPU.
// one message per upload
{
  "id": "evt_8812",
  "user": { "id": "u_331", "name": "Priya" },
  "type": "workout",              // "meal" | "mealprep" | "workout"
  "title": "Back squats 5x5",
  "category": "squat"             // optional: treadmill, bike, bench, squat, cable, dumbbell, mat
}

// also works from any script on the hosted page:
window.pushUpload({ user:{ name:"Priya" }, type:"meal", title:"Overnight oats" });

Before going live: only show members who opted in, and use first names or handles. Each member gets the same look every time (built from their user id). If no category is sent, the scene picks the station from the title. This preview can't reach outside servers, so the live hookup only works once you host the file yourself.
